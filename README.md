# Goo Field

Interactive monochrome metaball / SDF composition with a Gray-Scott reaction-diffusion background, sci-fi WebAudio, and an oscilloscope.

Single self-contained page: open `index.html` in a browser (no build step).

## Controls

- **Move** — cursor attracts/repels the goo; bass drone modulates near centre
- **Click** — pluck, shockwave, chromatic-aberration flash, RD bloom, layout morph
- **Scroll** — sections morph the layout and reveal tracking labels
- **M** — mirror · **I** — invert
- Panel — ball count, plus marks, RD field, contours, glow, springs, cursor, volume
